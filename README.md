## 🚀 Getting Started

### Prerequisites
- Node.js (v20 or higher)

### Running the Website

```bash
# Start the server
npm start
# or
node server.mjs
```

Then open your browser and visit: http://127.0.0.1:3000

## ✨ Features

- **Luxurious Design**: Premium color scheme with gold gradients and deep navy backgrounds
- **Responsive Layout**: Optimized for desktop, tablet, and mobile devices
- **Interactive Elements**: Smooth animations, hover effects, and scroll interactions
- **Multiple Sections**:
  - Hero/Introduction
  - About & Stats
  - Musical Journey
  - Literary Works
  - Innovations & Inventions
  - Social Media Links

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Backend**: Node.js (HTTP Server)
- **Fonts**: Playfair Display, Montserrat (Google Fonts)
- **Design**: Custom CSS with animations and gradients
